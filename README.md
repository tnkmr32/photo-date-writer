# Photo Date Writer

JPG画像のEXIFから撮影日時を読み取り、フィルムカメラ風の日付印字を画像に追加するツールです。

## 特徴

**フィルムカメラの日付機能を再現**  
フィルムカメラの日付機能は、フィルムに直接光を照射して日付を焼き込みます。このツールは、その効果をデジタル画像で再現し、フィルムに写り込んだような自然な日付印字を実現します。

- **7セグメント風フォント**: デジタル表示らしいレトロな雰囲気
- **輝度加算エフェクト**: 光で焼き込まれたような自然な見た目
- **カラー/モノクロ自動判定**: 画像に応じて最適な色を選択
- **Portrait画像対応**: 縦向き写真も自動回転して処理

## 主な機能

- JPG/JPEG画像のEXIFデータから撮影日時を自動取得
- フィルム風の「YY MM DD」形式で日付を画像右下に印字
- 単一ファイル処理とフォルダ一括処理の両方に対応
- アスペクト比3:2の画像に最適化
- Portrait（縦向き）画像の自動回転
- グレースケール/カラー画像の自動判定と色調整
- 元の画像品質を保持（JPEG品質95）

## 必要要件

- Python 3.x
- Pillow >= 10.0.0
- NumPy >= 1.24.0

## インストール

```bash
# 1. リポジトリをクローン
git clone <repository-url>
cd photo-date-writer

# 2. 仮想環境を作成（推奨）
python3 -m venv venv

# 3. 仮想環境をアクティベート
source venv/bin/activate  # macOS/Linux
# または
venv\Scripts\activate     # Windows

# 4. 依存パッケージをインストール
pip install -r requirements.txt
```

## 使い方

### 基本的な使い方

```bash
# 単一ファイルを処理
python main.py <入力ファイル.jpg> <出力ファイル.jpg>

# フォルダ内の全JPGファイルを一括処理
python main.py <入力フォルダ> <出力フォルダ>
```

### 使用例

```bash
# 単一ファイル処理
python main.py input/photo.jpg output/photo.jpg

# フォルダ一括処理
python main.py ~/Pictures/Archive/2026/2026-01/jpg/share output/processed

# 絶対パスも使用可能
python main.py ~/Pictures/photo.jpg ~/Desktop/photo_with_date.jpg
```

### フォルダ処理の詳細

- 入力フォルダ内の全JPG/JPEG ファイル（大文字小文字問わず）を自動検出
- 出力フォルダが存在しない場合は自動作成
- 各ファイルの処理結果（成功/失敗）を表示
- 処理完了後に統計情報（成功数/失敗数）を表示

## 技術仕様

### 日付印字仕様

- **日付フォーマット**: `YY    MM    DD`（7セグメント風表示）
- **配置位置**: 画像右下（マージン: 60px）
- **フォントサイズ**: 40pt（BM-HANNA_TTF.ttf）
- **色**:
  - グレースケール画像: オレンジ系 `(255, 150, 80)`
  - カラー画像: 赤系 `(255, 80, 80)`
- **エフェクト**: 輝度加算による光の焼き込み効果

### 画像処理仕様

- **対象アスペクト比**: 3:2 ±1% の許容誤差
- **出力形式**: JPEG（品質95）
- **Portrait画像処理**: 自動的に左90度回転（反時計回り）
- **色空間**: RGB（入力画像が他の色空間の場合は自動変換）

### モジュール構成

- `main.py` - コマンドラインインターフェース
- `image_processor.py` - 画像処理のメインロジック
- `exif_reader.py` - EXIF情報の読み取り
- `image_analyzer.py` - 画像分析（向き、モノクロ判定、アスペクト比）
- `image_effects.py` - フィルム風エフェクトの適用
- `file_handler.py` - ファイル/フォルダ操作、バッチ処理

## 注意事項

- EXIFに撮影日時情報がない画像は処理できません
- アスペクト比が3:2（±1%）でない画像はエラーとなります
- 入力ファイルはJPEG形式である必要があります
- Portrait画像は自動的に回転されます（元の向きには戻りません）
- `fonts/BM-HANNA_TTF.ttf` フォントファイルが必要です

## エラーハンドリング

処理中に発生する可能性のあるエラー：

- **EXIFデータなし**: 撮影日時情報が取得できない画像
- **アスペクト比エラー**: 3:2以外の画像
- **ファイル形式エラー**: JPEG以外の画像ファイル
- **フォントファイルなし**: 指定フォントが見つからない

バッチ処理では、エラーが発生したファイルをスキップして処理を継続し、最後に失敗ファイルのリストを表示します。
