# 写真日付印字プログラム 開発計画（MVP版）

## プロジェクト概要

JPGファイルから日付情報を読み取り、写真の右下に日付を印字して出力する最小限のプログラムを開発する。

## 技術スタック

- **言語**: Python 3.x
- **主要ライブラリ**:
  - Pillow (PIL): 画像処理と日付の描画（EXIF読み取りも含む）

## MVP の範囲

**含まれる機能**:

- 単一のJPGファイルを入力として受け取る
- EXIF データから撮影日時を読み取る
- 日付を "YYYY/MM/DD" 形式で画像右下に印字
- 固定のフォント設定（白色、背景半透明）
- 新しいファイルとして出力

**含まれない機能（将来の拡張）**:

- バッチ処理・ディレクトリ処理
- フォーマットやスタイルのカスタマイズ
- 詳細なエラーハンドリング
- 自動テスト
- パッケージング

## 開発ステップ

### ステップ1: プロジェクト構成の作成

- **作業内容**:
  - `requirements.txt` - Pillow のみ
  - `README.md` - 基本的な使い方のみ
  - `main.py` - すべての機能を1ファイルに実装
- **成果物**: 最小限のファイル構成

### ステップ2: コア機能の実装

- **作業内容**:
  - `main.py` に以下を実装:
    - EXIF から DateTimeOriginal を取得
    - 日付を "YYYY/MM/DD" に変換
    - PIL で画像を開く
    - 右下に白文字で日付を描画
    - 新しいファイルとして保存
- **機能詳細**:
  - 固定設定: フォントサイズ32、白色、右下マージン20px
  - EXIFがない場合はエラーメッセージを表示して終了
- **成果物**: 動作する main.py

### ステップ3: 簡単な使い方の文書化

- **作業内容**:
  - README.md に実行方法を記載
  - 基本的な使用例のみ
- **成果物**: 最小限のドキュメント

## 想定される使用例

```bash
# 単一ファイルの処理
python main.py input.jpg output.jpg
```
