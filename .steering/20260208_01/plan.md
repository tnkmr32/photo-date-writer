# 写真日付印字プログラム 開発計画

## プロジェクト概要

JPGファイルから日付情報を読み取り、写真の右下に日付を印字して出力するプログラムを開発する。

## 技術スタック

- **言語**: Python 3.x
- **主要ライブラリ**:
  - Pillow (PIL): 画像処理と日付の描画
  - piexif または Pillow の ExifTags: EXIF データから撮影日時を取得

## 開発ステップ

### ステップ1: プロジェクト構成の作成

- **目的**: 基本的なプロジェクト構造を整える
- **作業内容**:
  - `requirements.txt` - 必要なライブラリの記述
  - `README.md` - プロジェクトの説明とセットアップ手順
  - `.gitignore` - Python プロジェクト用
  - `src/` ディレクトリ - ソースコード配置
  - `tests/` ディレクトリ - テストコード配置
  - `input/` ディレクトリ - 入力画像のサンプル配置場所
  - `output/` ディレクトリ - 出力画像の保存場所
- **成果物**: 基本ディレクトリ構造とドキュメントファイル

### ステップ2: コア機能の実装

- **目的**: 写真から日付を読み取り、印字する基本機能の実装
- **作業内容**:
  - `src/photo_date_writer.py` - メインモジュール
    - EXIF データから撮影日時を取得する関数
    - 画像に日付テキストを描画する関数
    - 入力/出力ファイルのハンドリング
  - `src/config.py` - 設定管理（フォント、色、位置など）
- **機能詳細**:
  - EXIF の DateTimeOriginal または DateTime タグから日付を抽出
  - フォーマット: "YYYY/MM/DD" または "YYYY-MM-DD" など設定可能
  - 右下の位置にマージンを持たせて配置
  - テキストの背景を半透明にして可読性を確保
  - 元の画像の品質を保持
- **成果物**: 基本的な日付印字機能を持つモジュール

### ステップ3: コマンドラインインターフェース (CLI) の実装

- **目的**: ユーザーが簡単に使えるCLIツールの作成
- **作業内容**:
  - `src/main.py` または `photo_date_writer` スクリプト
  - argparse を使用したコマンドライン引数の処理
- **オプション例**:
  - `-i, --input`: 入力ファイル/ディレクトリ
  - `-o, --output`: 出力ディレクトリ
  - `-f, --format`: 日付フォーマット指定
  - `--font-size`: フォントサイズ
  - `--font-color`: フォント色
  - `--position`: 配置位置（右下、左下など）
  - `--margin`: マージン設定
  - `-r, --recursive`: ディレクトリ内を再帰的に処理
- **成果物**: 使いやすいCLIツール

### ステップ4: エラーハンドリングとロギング

- **目的**: 堅牢性の向上とデバッグ支援
- **作業内容**:
  - EXIF データが存在しない場合の処理
  - 対応していないファイル形式の検出
  - 画像処理中のエラーハンドリング
  - logging モジュールを使用したログ出力
  - 進捗表示（複数ファイル処理時）
- **成果物**: エラーハンドリングとロギング機能

### ステップ5: テストの実装

## 技術的考慮事項

### フォント

- システムフォントを使用（Arial, Helvetica など）
- 日本語対応が必要な場合は、フリーフォントを同梱または指定
  - 例: IPAフォント、Noto Sans JP

### 画像品質

- JPEG 品質パラメータを設定可能に（デフォルト 95）
- EXIF データを保持して出力

### パフォーマンス

- 大量の画像を処理する場合、進捗バーを表示
- メモリ効率を考慮した実装

## 想定される使用例

```bash
# 単一ファイルの処理
python src/main.py -i input/photo.jpg -o output/

# ディレクトリ内の全ファイルを処理
python src/main.py -i input/ -o output/ -r

# カスタマイズして処理
python src/main.py -i input/photo.jpg -o output/ \
  --format "%Y/%m/%d" --font-size 36 --font-color white
```

## リスクと対策

- **リスク**: 特定のJPGファイルにEXIFデータが存在しない
  - **対策**: ファイルの更新日時を使用する、またはユーザーに日付を入力させるオプション
- **リスク**: フォントが環境によって異なる
  - **対策**: フォントファイルをプロジェクトに含める、またはシステムフォントを検出する仕組み
- **リスク**: 大きな画像ファイルでメモリ不足
  - **対策**: 画像処理時のメモリ管理を最適化、必要に応じてリサイズ
